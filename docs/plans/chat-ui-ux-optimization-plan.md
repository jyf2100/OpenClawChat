# 聊天消息区域 UI/UX 优化计划

**项目**: OpenClaw Tauri Desktop
**创建日期**: 2025-02-09
**状态**: 计划中

---

## 1. 总体目标

优化聊天消息区域的用户界面和交互体验，提升 Discord 风格的一致性和用户体验。

---

## 2. 优化范围

### 2.1 涉及组件

- `src/components/layout/MainChat.tsx` - 主聊天区域
- `src/components/chat/MessageList.tsx` - 消息列表
- `src/components/chat/MessageItem.tsx` - 消息项
- `src/components/chat/InputArea.tsx` - 输入区域
- `src/styles/globals.css` - 相关样式

### 2.2 约束条件

- 保持 Discord 风格的设计语言
- 不修改 TypeScript 类型定义
- 保持现有功能正常工作
- 使用现有的 CSS 变量系统

---

## 3. 详细优化项

### 3.1 消息显示优化

#### 3.1.1 消息分组（同用户连续消息合并）

**当前状态**: 每条消息都显示完整的头像和头部信息

**优化方案**:
- 检测连续的同用户消息
- 合并显示：第一条消息显示完整头部，后续消息仅显示内容
- 添加时间间隔阈值（5分钟内视为连续）

**实现位置**: `MessageList.tsx`, `MessageItem.tsx`

#### 3.1.2 代码块语法高亮样式

**当前状态**: 代码块有基础样式，但无语法高亮

**优化方案**:
- 使用 CSS 为代码块添加基础语法高亮
- 添加代码块头部显示语言标识
- 优化代码块复制按钮样式

**实现位置**: `MessageItem.tsx`, `globals.css`

#### 3.1.3 图片消息预览和放大

**当前状态**: 图片有基础显示，有点击处理但未实现预览

**优化方案**:
- 添加图片点击放大预览功能
- 实现模态框预览组件
- 支持缩放和关闭

**实现位置**: 新建 `ImagePreview.tsx`, `MessageItem.tsx`

#### 3.1.4 相对时间显示

**当前状态**: 显示具体时间（HH:MM）

**优化方案**:
- 实现相对时间函数
- "刚刚" - 1分钟内
- "N分钟前" - 1小时内
- "今天 HH:MM" - 今天
- "昨天 HH:MM" - 昨天
- "MM-DD HH:MM" - 更早

**实现位置**: 新建 `utils/timeFormat.ts`, `MessageItem.tsx`

#### 3.1.5 消息回复/引用样式

**当前状态**: 无回复/引用功能

**优化方案**:
- 添加引用消息的视觉样式
- 显示被引用消息的预览
- 添加引用标识和分隔线

**实现位置**: `MessageItem.tsx`, `globals.css`

---

### 3.2 输入区域优化

#### 3.2.1 发送预览功能

**当前状态**: 无预览功能

**优化方案**:
- 添加预览模式切换
- 预览模式下显示 Markdown 渲染结果
- 添加预览切换按钮

**实现位置**: `InputArea.tsx`

#### 3.2.2 Emoji 选择器

**当前状态**: 无 Emoji 选择器

**优化方案**:
- 添加 Emoji 选择器组件
- 常用 Emoji 快速选择
- 搜索功能

**实现位置**: 新建 `EmojiPicker.tsx`, `InputArea.tsx`

#### 3.2.3 @提及功能（高亮显示）

**当前状态**: 无 @提及功能

**优化方案**:
- 检测 @符号触发提及列表
- 高亮显示提及文本
- 添加提及列表组件

**实现位置**: 新建 `MentionList.tsx`, `InputArea.tsx`

#### 3.2.4 输入框自动高度调整优化

**当前状态**: 有基础自动高度，最大200px

**优化方案**:
- 优化自动高度算法
- 确保高度变化平滑
- 添加最大高度时的滚动提示

**实现位置**: `InputArea.tsx`

#### 3.2.5 清空输入按钮

**当前状态**: 无清空按钮

**优化方案**:
- 添加清空按钮（X）
- 仅在有内容时显示
- 添加确认机制（长按或双击）

**实现位置**: `InputArea.tsx`

#### 3.2.6 发送按钮加载状态

**当前状态**: 按钮仅根据可发送状态禁用/启用

**优化方案**:
- 添加发送中的加载动画
- 区分发送中、等待响应等状态
- 优化按钮视觉反馈

**实现位置**: `InputArea.tsx`

### 3.3 交互增强

#### 3.3.1 消息右键菜单

**当前状态**: 无右键菜单

**优化方案**:
- 添加右键菜单组件
- 支持操作：复制、删除、引用
- 添加菜单动画效果

**实现位置**: 新建 `ContextMenu.tsx`, `MessageItem.tsx`

#### 3.3.2 消息选择/多选功能

**当前状态**: 无选择功能

**优化方案**:
- 添加长按触发选择模式
- 支持多选消息
- 添加批量操作工具栏

**实现位置**: `MessageList.tsx`, `MessageItem.tsx`

#### 3.3.3 流式消息打字机效果

**当前状态**: 有基础流式指示器

**优化方案**:
- 优化打字机动画
- 添加光标闪烁效果
- 平滑的文本追加动画

**实现位置**: `MessageItem.tsx`, `globals.css`

#### 3.3.4 滚动到新消息按钮

**当前状态**: 无滚动按钮

**优化方案**:
- 检测用户滚动位置
- 显示"有新消息"按钮
- 点击滚动到最新消息

**实现位置**: `MessageList.tsx`

---

### 3.4 视觉细节

#### 3.4.1 用户消息头像颜色个性化

**当前状态**: 固定颜色（用户用 accent，助手用绿色）

**优化方案**:
- 基于用户名生成一致的颜色
- 使用 HSL 颜色空间
- 确保颜色对比度足够

**实现位置**: 新建 `utils/avatarColor.ts`, `MessageItem.tsx`

#### 3.4.2 消息状态图标

**当前状态**: 无状态图标

**优化方案**:
- 发送中：时钟图标
- 已送达：单勾
- 已读：双勾
- 错误：红色感叹号

**实现位置**: `MessageItem.tsx`, `globals.css`

#### 3.4.3 错误消息特殊样式

**当前状态**: 无特殊样式

**优化方案**:
- 添加错误状态视觉标识
- 红色边框或背景
- 错误图标

**实现位置**: `MessageItem.tsx`, `globals.css`
